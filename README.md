# DynaConTalk project page

Static academic project homepage adapted from the public MoMask page template.

Public site: <https://zhuyifeiabcd1.github.io/DynaConTalk/>

## Local preview

```bash
python3 -m http.server 8123
```

Then open `http://127.0.0.1:8123`.

## Release status

- Paper and code buttons are intentionally disabled until their public URLs are available.
- Add the final author list, venue, arXiv link, code link, and BibTeX after release.

Only assets referenced by the published page are included. Method videos and
generated examples are embedded from YouTube; the hero background remains a
small local MP4 under `static/video/dynacontalk/`.
